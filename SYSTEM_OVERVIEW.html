Get the single best stock with highest consensus

GET /api/v1/agents/top-stocks?limit=5&min_confidence=0.65

Get ranked list of top stocks

POST /api/v1/agents/compare-stocks?symbols=VNM&symbols=SSI

Compare multiple stocks side-by-side

GET /api/v1/agents/consensus-debate/{symbol}

🚀 Getting Started (3 Minutes)

Step 1: Add Frontend Component

import AIStockRanking from '@/components/dashboard/AIStockRanking'; export default function Dashboard() { return <AIStockRanking />; }

Step 2: Call API Endpoints

// Get best stock fetch('/api/v1/agents/best-stock') .then(r => r.json()) .then(data => console.log(`Best: ${data.best_stock}`)); // Get top 5 stocks fetch('/api/v1/agents/top-stocks?limit=5') .then(r => r.json()) .then(data => console.log(data.all_ranked));

Step 3: Interpret Results

  • Green (BUY) = Agents recommend buying
  • Yellow (HOLD) = Mixed signals, wait
  • Red (SELL) = Agents recommend selling
  • Confidence ≥ 80% = Excellent signals
  • Consensus ≥ 80% = Strong agent agreement
